About me

Background

I'm studying Computer Engineering at UC San Diego. I like working through how a project comes together, from what someone sees on the page to what the code is doing and where the data goes.

I want the things I build to be useful. When I'm working on something, I keep asking, what would make this easier for someone to use?

Technical experience

These are some of the tools I've used for the projects on this site.

Web development

  • HTML, CSS, and JavaScript for web pages and interfaces.
  • Next.js for the gym planning dashboard.

Backend and data

  • PHP and MySQL for collecting website data and building reports.
  • Python for data collection.
  • GitHub Actions, Linux, Apache, and DigitalOcean for the CSE 135 project.

Leadership

I'm also president of the Chancellor's Scholars Alliance. I work with the board on events, volunteering, and peer mentoring. I help keep track of what needs to get done and work with the different chairs to put those plans together.

Part of that is making sure people know what's happening and following through on the plans we make.

How I approach projects

  1. Figure out what the project needs to do and who it is for.
  2. Get the basic content and features working first.
  3. Add styling and extra behavior while keeping the basic page usable.
  4. Test it, fix problems, and explain what I'd change next.

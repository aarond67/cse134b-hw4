CSE 135

Bad Decisions Analytics

This was my CSE 135 project. I wanted a way to see what was happening on a test store, including errors and loading times. The store sends activity to a collector, and the reporting site uses that data for its reports.

Built with: PHP, MySQL, JavaScript, HTML, CSS, Apache, and Linux.

  • CSE 135 project archive
  • Analytics source code and documentation
What I built and how it works

What I built

There are reports for website errors, loading times, and where people stop during checkout. I also added a place for analyst comments and an option to download a report as a PDF.

How it works

  • PHP sessions keep track of who's signed in, and server-side checks control which reports they can see.
  • I used prepared statements for database queries and escaped text before displaying it on a page.
  • The interface mostly uses plain JavaScript and CSS.
  • GitHub Actions handles deployment to my DigitalOcean server.

Gym occupancy and planning

UCSD Gym Planner

The idea was to make it easier to check how crowded the UCSD gyms are and plan around that. The dashboard brings occupancy information into one place and also has options for workouts, meals, and a weekly schedule.

Built with: Python, Next.js, and JavaScript.

  • Open UCSD Gym Planner
Tools and forecast limits

The project uses Python, Next.js, and JavaScript. The forecasts depend on the data that's available. If there isn't enough matching data, the dashboard says so instead of showing an estimate it can't support.

CSE 110 · Team project

Meme Generator

My team built this for CSE 110. You can upload an image or choose a template, add your text, and download the finished meme. We wanted someone to be able to work through those steps without having to figure out a complicated editor first.

We used HTML, CSS, and JavaScript and hosted the app on GitHub Pages.
